# Design

## Purpose
UI/UX design, visual design, layout, and user experience work.

## Anti-Patterns
- Designing for yourself (not users)
- Too many fonts (max 2-3)
- Low contrast text
- Inconsistent spacing
- Decorative elements without purpose
- Ignoring mobile constraints
- No hover/focus states

## Behavioral Patterns
- Define user goal (what are they trying to do?)
- Sketch layout (wireframe first)
- Choose color palette (60-30-10 rule)
- Design components (buttons, cards, inputs)
- Test responsiveness (mobile → desktop)
- Check accessibility (contrast, alt text, focus)
- Get feedback (user testing if possible)
