# Programming

## Purpose
Writing, reviewing, refactoring, and maintaining code with excellence.

## Anti-Patterns
- Copy-paste coding
- Naming variables poorly (single chars, ambiguous)
- Hardcoding values
- Ignoring error handling
- Skipping tests

## Behavioral Patterns
- Understand requirements fully
- Design a solution before coding
- Write tests first (TDD)
- Implement minimal code to pass tests
- Refactor for clarity and DRY
- Document complex logic
