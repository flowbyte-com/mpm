# Writing

## Purpose
Clear, audience-appropriate writing with proper tone.

## Anti-Patterns
- Jargon without explanation
- Passive voice (when active is clearer)
- Wordiness
- Repeating the same words
- Starting with 'This document will...'

## Behavioral Patterns
- Identify target audience
- Match tone to context (formal/casual/technical)
- Use active voice
- Cut unnecessary words
- Vary sentence structure
- Proofread for clarity
